Labels. Pick exactly one:

- bug: something that should already work does not. The file is the one whose code is wrong.
- feature: a request for new behaviour. The file is the one where the change would mainly go.
- question: the reporter asks how something works and nothing needs to change. The file is none.
- docs: the documentation is wrong or missing. The file is the document to fix.

An issue phrased as a question is still a bug or docs issue if it shows that something is wrong; use question only when nothing needs to change.

The file is a path relative to the repository root, for example src/widgets/frobnicate.ts or docs/setup.md, or the word none.
